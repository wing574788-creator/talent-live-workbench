# 达人直播工作台 · 使用说明

给品牌方自己用的达人直播合作工作台：商品、达人、联系人、合作跟踪、跟进记录、样品台账、Excel 导入、AI 录入。数据全部存在这台电脑上。

## 1. 安装

1. 安装 **Node.js 22.19 或更高版本**（https://nodejs.org ，选 LTS 以上的版本，一路"下一步"）。
2. 打开"命令提示符"或 PowerShell，运行一次：`npm i -g pnpm`。
3. 把整个项目文件夹放到你想放的位置（比如桌面）。

## 2. 启动

双击项目文件夹里的 **`start.bat`**：

- 第一次会自动安装依赖（需要联网，几分钟）。
- 启动后浏览器自动打开 http://localhost:5173 。
- **关闭那个黑色窗口 = 停止服务**。工作时请保持它开着。

> 服务只监听本机（127.0.0.1），同一局域网的其他电脑访问不了；这是有意的，保护达人联系方式。

数据放在 `%APPDATA%\talent-live-workbench`（数据库、附件、AI 会话、备份）。想迁移到别的电脑，关闭服务后把这个文件夹整个拷过去即可。

## 3. 日常使用

| 页面 | 做什么 |
| --- | --- |
| 首页 | 今日待跟进、样品预警、近 7 天开播、一句话录入、今日概况 |
| 合作 | 看板（拖动卡片换阶段）和列表；点开卡片看商品、佣金、跟进 |
| 达人 / 联系人 / 商品 | 资料库；手机、微信、地址默认打码，点"查看"才显示 |
| 寄样 | 按达人的样品台账：寄出、签收、退回、质检、核销 |
| 导入 | 导入 Excel / CSV |
| 审核 | AI 和导入产生的敏感改动在这里确认 |
| 设置 | 跟进状态、预警天数、AI 模型、外发规则、备份、变更日志、自定义字段 |

几条要记住的规则：

- **样品按达人记账**：在外数量 = 累计寄出 − 累计退回 − 核销，系统自动算，不用手填。只有"已寄出"之后才计入在外。
- **佣金设在合作商品上**，每场合作、每个商品可以不同。
- **洽谈中的合作必须有下次跟进日期**，到期会出现在首页"今日待跟进"。
- 你在页面上手动改的内容直接生效，但都记在变更日志里，可以撤销（设置 → 变更日志）。

## 4. 导入钉钉多维表数据

没有固定模板，列对应关系由你自己指定：

1. 在钉钉多维表里把表格导出为 Excel（或 CSV）。
2. 打开「导入」，上传文件。可先用 `docs/samples/钉钉多维表导出示例.xlsx` 练手（全是虚构数据）。
3. **选 sheet 和表头行**：系统会猜表头在第几行、是什么类型的表（达人 / 商品 / 联系人 / 合作 / 寄样）。猜错了就改。
4. **映射列**：每一列选"导入到哪个字段"；认不出的列可以新建自定义字段、存为原始值或忽略。想让 AI 帮忙，点「AI 建议映射」（需要先配置模型，见第 5 节；只会发送表头和每列最多 3 个样本值，手机号等照样脱敏）。
5. **预览**：金额、日期、百分比的转换结果和重复项都会列出来；有问题的行可以导出成 Excel 改完再导。重复的达人（同平台同账号 ID）可选"合并 / 跳过 / 新建"，昵称相似只提示、不会自动合并。
6. **提交**：勾选"保存为模板"，下次表头相似的表会自动套用。导入的整批改动可以在「导入」页的批次里**一键回滚**。

## 5. 配置 AI 模型（可选）

不配置也能用，只是 AI 功能不可用。

1. 设置 → AI 模型 → **添加提供方**。国内推荐 **DeepSeek**；也支持 Anthropic、OpenAI、其他 OpenAI 兼容接口（通义、Kimi 等）和本机 Ollama。
2. 点"填写 Key"，粘贴你自己的 API Key。Key 只保存在这台电脑上，不会显示在页面上，也不会写进数据库。
3. 在下面给四个用途各选一个模型：录入提取、问答、首页摘要、导入映射建议。

### 隐私与外发

- **手机号、微信号、收货地址、真实姓名**发给模型前一律在本机替换成 `[手机号1]` 这样的占位符，**无法关闭**。图片不会发给模型。
- 设置 → 外发规则：可以整体关闭外发、限定只用境内或本机模型，也可以按模块、按字段禁止或打码。
- 设置 → 外发日志：每次发给模型的内容都记在这里（脱敏后的样子），可以随时核对、导出。

### 怎么用 AI 侧栏

右侧"AI 助手"，有两个模式：

- **录入**：粘贴聊天记录或一句话，例如"刚和小美的经纪人聊了，A001 佣金 25 个点，下周三播，样衣明天寄 A001 黑色 S、M 各一件"。AI 会整理成卡片：
  - 新增跟进、草稿合作、寄样草稿**直接写入**，卡片上可以撤销；
  - 改字段、金额、佣金、阶段、合并、删除、批量修改**只生成待审核卡片**，你可以在卡片上直接改字段再点"通过"。
  - 名字有多个同名候选时，AI 会让你点选，不会自己挑；一次录入只处理一个合作。
  - 金额、佣金必须带单位（"25 个点""1.2万"），并和你的原话逐字核对；佣金超过 50% 或明显偏离历史值会标黄提醒；"下周三"这样的日期由程序算好，卡片上显示"10月21日 周三"。
- **问答**：只查询、不改数据，例如"签收超过两周还没开播的有哪些"。回答里的名字可以点开查看；查不到就会说查不到。
- **截图**：点"截图"或直接粘贴图片。截图先在本机识别成文字（需要 Windows 的中文 OCR 语言包），你核对、修改文字后才发送；图片本身不会发给模型。

换模型之前，建议先跑一遍工具调用回归集，看新模型调用工具是否稳定：

```
pnpm --filter @workbench/server ai:regress
```

它会用虚构数据调用你已配置的模型，逐项显示通过或失败。

## 6. 备份与恢复

- **自动备份**：每天自动把数据库备份一份，自动备份保留最近 30 份。默认放在数据目录的 `backups` 里；建议在 设置 → 备份与恢复 把"备份目录"改到另一块硬盘或网盘同步目录，防止电脑坏了一起丢。
- **手动备份**：设置 → 备份与恢复 → 立即备份。
- **从备份恢复**（页面上）：设置 → 备份与恢复 → 选一份 →"从这份恢复"。系统会先自动做一份"恢复前"备份，**关闭并重新启动服务后**换上；原数据库保留为 `workbench.db.before-restore`。
- **数据库文件丢了 / 打不开**：关闭服务，在项目文件夹打开命令行运行

  ```
  pnpm backup restore
  ```

  会从最近一份备份恢复（也可以指定文件名：`pnpm backup restore auto-20261018-090000.db`）。然后重新启动。
- 其他命令：`pnpm backup list` 查看备份，`pnpm backup backup` 立即备份一份。
- 截图和质检照片不在数据库里，在数据目录的 `attachments` 文件夹；整体备份请拷贝整个数据目录。

## 7. 常见问题

- **页面打不开**：确认黑色启动窗口还开着；看窗口里有没有红色报错。
- **AI 提示"还没有配置模型"**：见第 5 节。
- **AI 提示"拒绝了请求"**：API Key 不对或没有余额。
- **截图识别提示没有语言包**：Windows 设置 → 时间和语言 → 语言和区域 → 添加"中文（简体）"，勾选"OCR"功能。
- **想改"应寄回日期"的天数、预警天数、跟进状态**：设置页最上面几块。
