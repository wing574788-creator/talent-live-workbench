# 达人直播工作台 · 开发交接包

这个文件夹是交给 Claude Code 开始开发的起点。

## 怎么用

1. 把这个文件夹移动到你想放代码的位置（也可以就放在桌面）。
2. 用 Claude Code 打开这个文件夹（终端里 `cd` 进来后运行 `claude`，或在桌面版 / VS Code 里打开这个文件夹）。
3. 对它说：**"读一下 CLAUDE.md 和 docs，从阶段 0 开始开发。"**

Claude Code 会自动读取 `CLAUDE.md` 里的约定，并按 `docs/DEV_PLAN.md` 一个阶段一个阶段地做。

## 文件说明

| 文件                    | 内容                                                          |
| ----------------------- | ------------------------------------------------------------- |
| `CLAUDE.md`             | 给 Claude Code 的开发约定：技术栈、架构规则、容易做错的业务点 |
| `docs/PRD.md`           | 完整需求文档（在线 PRD 的导出版）                             |
| `docs/DEV_PLAN.md`      | 分 9 个阶段的开发计划和验收标准                               |
| `design/mockups/*.html` | 4 个页面的布局原型，双击用浏览器打开，左侧导航可以互相跳转    |
| `design/preview/*.png`  | 原型截图                                                      |

## 开发前建议准备

- 安装 Node.js 22.19 或更高版本，以及 pnpm（`npm i -g pnpm`）。
- 一份钉钉多维表导出的样例（可以把联系方式改成假的），用于测试导入。
- 想用的模型和 API Key（可以开发到阶段 7 再定）。
