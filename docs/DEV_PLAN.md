# 开发计划（V1）

按阶段推进，每个阶段结束时都能启动、能演示、测试通过。阶段内的任务顺序可以调整，阶段之间不要跳。需求细节见 `PRD.md` 对应章节。

## 阶段 0：脚手架与技术验证

目标：项目能跑起来，关键技术风险先验证掉。

- [x] pnpm workspace：`apps/web`、`apps/server`、`packages/shared`；TypeScript、ESLint、Prettier、Vitest 配好。
- [x] 一条命令同时启动前后端（如 `pnpm dev`），Windows 下可用。
- [x] 后端 Hono 只监听 127.0.0.1；前端通过 Vite 代理访问 `/api`。
- [x] SQLite（WAL）+ Drizzle，迁移脚本可用；数据目录可配置（默认放在用户目录下的应用数据文件夹）。
- [x] **Pi SDK 验证**（PRD 11.2）：最小示例创建会话、关闭内置工具、注册一个自定义工具、通过 SSE 流式返回、能 abort；确认 `tool_call` 拦截在 SDK 模式下是否生效。结论写进 `docs/DECISIONS.md`。
- [x] 前端外壳：左侧导航（首页、合作、达人、联系人、商品、寄样、审核、导入、设置）+ 右侧可收起的 AI 侧栏占位，样式参照 `design/mockups`。

验收：`pnpm dev` 后浏览器能打开空壳页面；Pi 最小示例能对话并调用自定义工具。

## 阶段 1：数据模型与领域服务地基

目标：所有表、公共字段、变更日志和审核队列先立起来。

- [x] 公共字段与 `users` 表（单人默认用户）。
- [x] 全部实体表：商品（含规格、平台商品、尺码表、图片）、达人、平台账号、联系人、达人-联系人关联、合作、合作商品、跟进记录、寄样单与明细、退样单与明细、核销记录、附件。
- [x] 自定义字段：`field_def` 表 + 各实体 `custom` JSON 列（PRD 4.7）。
- [x] `change_log`、`pending_change`（审核队列）、`import_batch`、`mapping_template`、`outbound_policy`、`outbound_log`、`summary_cache`。
- [x] 领域服务基类：统一处理校验（zod）、乐观锁、写变更日志、敏感操作转审核、撤销。
- [x] 单元测试覆盖：变更日志、撤销、乐观锁冲突、敏感操作进审核。

验收：测试通过；能通过脚本插入示例数据并撤销。

## 阶段 2：基础资料（商品、达人、联系人）

- [x] 商品库：列表（筛选、排序、列显隐、保存视图）、详情抽屉、色码规格、尺码表、多图上传（存本地附件目录）。
- [x] 达人库：多平台账号；"平台 + 账号 ID"实时查重；昵称相似提示疑似重复；合并（走审核队列）。
- [x] 联系人库：类型（本人 / MCN / 经纪人 / 私人商务）、关联多个达人、主要对接人。
- [x] 敏感字段（微信、手机、地址、真实姓名）列表默认打码，点击查看。
- [x] 自定义字段可作为列表列显示和筛选。

验收：PRD 5.2 验收标准。

## 阶段 3：合作跟踪与跟进记录

- [x] 合作：看板（9 个主线阶段，拖拽改阶段）+ 列表视图；旁支状态在列表中查看。参照 `design/mockups/02-cooperations.html`。
- [x] 合作商品：每个商品单独的佣金率、直播价、机制。
- [x] 洽谈中的跟进状态、跟进次数、距上次跟进天数；必须有下次跟进日期；连续"待回复"提醒（PRD 5.3）。
- [x] 跟进记录：挂在合作、达人或联系人上，时间线显示；保存后同步下次跟进日期。
- [x] 阶段自动推进规则（PRD 5.3 验收），且可手动改回；流失/放弃必须填原因。

验收：PRD 5.3、5.4 验收标准。

## 阶段 4：达人样品台账

- [x] 寄样单：待寄样 → 已寄出 → 已签收；应寄回日期默认规则（开播日 + N 天，未排期按签收日 + M 天）。
- [x] 退样单：选达人后列出全部在外样品，勾选款色码和数量，逐项质检、上传照片、选处理结果；按款色码从最早寄出开始冲抵。
- [x] 核销（报损、买断、赠送等）。
- [x] 在外结余计算（按款号+款名+颜色+尺码），逾期判断。
- [x] 达人详情"样品台账"标签页：在外结余、寄出/退回流水、累计汇总。参照 `design/mockups/03-influencer-samples.html`。
- [x] 寄样页：待寄样 / 在外 / 有逾期 / 质检待处理 / 已结清筛选，按达人汇总，批量标记寄出，登记退回面板。参照 `design/mockups/04-samples-return.html`。
- [x] 达人"回收问题次数"自动累计；结清后可清除收货地址。

验收：PRD 5.5 验收标准；包含交叉合作（一个包裹含两场合作样衣）的测试用例。

## 阶段 5：首页与审核

- [x] 首页：四个数字卡片、今日待跟进、寄样预警（按达人汇总）、近 7 天开播、待审核数量。参照 `design/mockups/01-home.html`。
- [x] 审核页：改动前后对比，逐条或整批通过/驳回，冲突检测。
- [x] 变更日志页：按条或按批撤销。

验收：PRD 5.1、5.6 验收标准（首页列表 1 秒内显示）。

## 阶段 6：自定义 Excel 导入导出

- [x] 导入向导 10 步（PRD 6.1）：上传、选 sheet 和目标、识别表头、列映射、值转换、枚举映射、预演、查重裁决、提交、保存模板。
- [x] 值转换器（PRD 6.2）：日期、金额（分）、粉丝数（"12.3w"等）、百分比、平台归一、多值拆分、无法解析存原始值；每个转换器都要有单元测试。
- [x] 模板按表头特征自动匹配。
- [x] 导入批次整批回滚，冲突逐条处理。
- [x] 导出：任一列表导出 .xlsx；全量导出（每类实体一个 sheet）。

验收：PRD 6.6 验收标准。先请用户提供一份钉钉多维表导出的脱敏样例做测试。

## 阶段 7：AI 助手

- [x] 模型配置页：Anthropic、OpenAI、OpenAI 兼容（DeepSeek / 通义 / Kimi）、本地 Ollama；按用途指定模型；默认留空，未配置时 AI 功能友好提示。
- [x] 外发过滤器与外发配置（全局 / 模块 / 字段）、固定脱敏规则、外发日志。
- [x] 领域工具（PRD 7.2）：只读、低风险写、敏感写（只生成待审核）、辅助（当前时间、导入映射建议）。
- [x] 护栏（PRD 7.3）：候选目标必须确认、金额与原文逐字核对、异常佣金警告、相对日期程序解析、保留出处、批量上限 200。
- [x] AI 侧栏：SSE 流式对话、停止按钮、改动卡片（可在卡片上改字段再确认）。
- [x] 一句话录入、问答、首页摘要（按天缓存）、导入映射建议。
- [x] 截图录入：本地 OCR（先做选型对比，结论写进 DECISIONS.md），再按外发规则发送文字。
- [x] 工具调用回归测试集：一组固定输入和期望的工具调用，换模型前可以一键跑。

验收：PRD 7、8 节验收标准；外发日志中没有未脱敏的手机号、微信号或地址。

## 阶段 8：备份与收尾

- [x] 每日自动备份到指定目录，保留 30 份；手动备份与恢复。
- [x] 设置页：自定义字段、枚举选项（含跟进状态）、预警阈值（N、M、3 天）、备份目录。
- [x] 端到端测试覆盖主流程：建达人 → 建合作 → 洽谈多轮跟进 → 待寄样 → 寄出 → 开播 → 退样质检 → 完成。
- [x] 用户使用说明（中文）：安装、启动、导入钉钉数据、配置模型、备份恢复。

验收：PRD 5.8 验收标准；用户能按说明从零装好并导入数据。
